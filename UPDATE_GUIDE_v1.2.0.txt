창원경일고 진학설계 시스템 v1.2.0 업데이트

주요 변경
1. 1·2·3학년 공용 화면 + 현재 학년 선택
2. 5등급 평균의 9등급 참고 환산 자동 표시
3. PDF/성적 사진 다중 선택·다중 드롭
4. 캡처 이미지 Ctrl+V 반복 붙여넣기 누적
5. 교과군/조합/학기별/전체/목표등급/Excel에 9등급 환산 병기

GitHub 업데이트 방법
1. v1.2.0 source ZIP을 압축 해제합니다.
2. 기존 jinhak-system 저장소의 파일을 새 버전 파일로 덮어 업로드합니다.
3. Commit changes 합니다.
4. Actions → Deploy to GitHub Pages에서 자동 실행을 확인합니다.
5. build와 deploy가 모두 초록 체크가 되면 완료입니다.
6. 사이트에서 Ctrl+F5 또는 시크릿 창으로 열어 상단 배지가
   `v1.2.0 · PDF/OCR · 5→9등급 환산 · 학기별 분석`인지 확인합니다.

주의
- 5→9 환산은 사용자가 제공한 Excel의 VLOOKUP 환산표를 그대로 옮긴 상담용 참고값입니다.
- 대학별 공식 환산식과 동일하다고 가정하면 안 됩니다.
- 원 5등급 평균은 그대로 보존됩니다.
