창원경일고 학생부 성적분석 시스템 v1.4.0 업데이트

1. jinhak-system-v1.4.0-update.zip 압축을 풉니다.
2. 압축 안의 jinhak-system-main 폴더 내용 전체를 기존 GitHub jinhak-system 저장소 루트에 업로드하여 같은 경로 파일을 덮어씁니다.
3. Commit changes를 누릅니다.
4. Actions > Deploy to GitHub Pages에서 build와 deploy가 모두 초록색인지 확인합니다.
5. 사이트를 새 창/시크릿 창에서 열고 상단 배지가 `v1.4.0 · 공식 학생부 표 정밀인식 · 5개 학기 검증`인지 먼저 확인합니다.
6. 이전 버전에서 잘못 반영된 성적은 IndexedDB에 남아 있을 수 있습니다. 검증 시 시크릿 창을 권장합니다.
7. 학생부 PDF를 다시 업로드한 뒤 자동인식 요약칩에서 1-1, 1-2, 2-1, 2-2, 3-1 모두 `등급 n건`이 1건 이상인지 확인합니다.
8. 검토표가 맞으면 반영 방식은 `기존 성적 전체를 이번 자동추출 결과로 대체(권장)`을 선택해 반영합니다.
