창원경일고 학생부 내신분석 시스템 v1.3.0 업데이트

1. jinhak-system-v1.3.0-update.zip 압축을 풉니다.
2. GitHub jinhak-system 저장소에 압축 해제한 파일/폴더를 덮어 업로드합니다.
3. Commit changes를 누릅니다.
4. Actions > Deploy to GitHub Pages에서 build와 deploy가 모두 초록색인지 확인합니다.
5. 사이트는 Ctrl+F5 또는 시크릿 창에서 열어 v1.3.0 배지를 확인합니다.
6. 이전 버전에서 잘못 자동저장된 성적이 있으면 새 세션(시크릿 창)에서 같은 PDF를 다시 불러와 검증합니다.

검증 기준
- 봉사활동 날짜/학교명이 과목으로 나타나지 않아야 합니다.
- 자동추출 검토표의 평가방식은 '등급' 또는 '성취평가'로 표시됩니다.
- 3학년 1학기까지 기록된 PDF라면 1-1, 1-2, 2-1, 2-2, 3-1이 모두 인식되어야 합니다.
