창원경일고 진학설계 시스템 v1.2.1 업데이트

핵심 수정
- 생기부 PDF의 학년/학기 셀 행 병합(rowspan) 구조를 보정했습니다.
- 숫자형 학년/학기 문맥을 후속 과목 행에 상속합니다.
- 2학기 첫 행에 학기 숫자만 나타나는 경우를 인식합니다.
- `국어 | 국어`처럼 교과명과 과목명이 같은 행이 통째로 누락되던 문제도 수정했습니다.
- 학기별 분석 배지는 실제 `n/5학기 인식`으로 표시합니다.
- 누락 학기가 있으면 경고하고, 전체 행도 불완전 자료임을 표시합니다.

GitHub 적용
1. jinhak-system-v1.2.1-update.zip 압축 해제
2. 압축 안의 파일/폴더를 기존 jinhak-system 저장소에 그대로 덮어쓰기
3. Commit changes
4. Actions에서 build / deploy 모두 초록 체크 확인
5. 사이트를 Ctrl+F5 또는 시크릿 창에서 열어 상단 v1.2.1 배지 확인
6. 같은 3학년 생기부 PDF를 다시 불러와 `5/5학기 인식` 여부 확인

주의
- 기존 IndexedDB 자동저장 자료에는 이전에 잘못 귀속된 학기 정보가 남아 있을 수 있습니다.
- 이 수정 검증 시에는 기존 자동저장 성적을 초기화하거나 새 브라우저/시크릿 창에서 PDF를 다시 불러오는 것이 안전합니다.
